In order to solve this problem, the author introduced the framework Transformers Programs that takes into account different constraints on the transformer model which helps to clear, deterministic relationship between Transformer components and RASP-like programming constructs. In the following subsections, we will outline the designs of these programs, the specific constrains applied and the optimization process that ensures effective training.  

\subsection{Distangled Residual Stream}

This is one of the critical aspect in the architecture, where the data belonging to different categories in the residual is encoded in distinct and non overlapping space. This ensures that the model's computations are interpretable and modular throughout its layers.
\begin{itemize}
    \item \textbf{Input Representation:} The input embeddings is a set of data from different categorical variables, which are concatenated to form the input representation. The residual stream encodes \( m \) categorical variables, all with cardinality \( k \), resulting in input embeddings \( x \in \{0,1\}^{N \times mk} \). For example, in our minimal Transformer Program, the initial input embeddings are structured to represent two categorical variables- tokens and positions.
    
    \item \textbf{Reading Variables:} Each layer reads a fixed set of input variables from the residual stream. For achieving this, the  projection matrix \( W \in \mathbb{R}^{mk \times k} \) is defined by an indicator \( \pi \in \{0,1\}^m \) such that \( \sum_{i=1}^{m} \pi_i = 1 \). That is,

    \[
    W = \begin{bmatrix}
    \pi_1 I_k \\
    \vdots \\
    \pi_m I_k
    \end{bmatrix},
    \]
    
    where \( I_k \) is the \( k \times k \) identity matrix.This is similar to one-hot indicator vectors. The interaction of each attention head with the residual stream is controlled by gating vectors \( \pi_K, \pi_Q, \pi_V \), which specify the variables to use as keys, queries, and values, respectively. 
    
    \item \textbf{Writing Variables:} Each layer writes into a new non-overlapping subspace in the residual stream. To achieve this, the output of each module is concatenated with its input i.e.  \( x_i = [x_{i-1}; h(x_{i-1})] \)  where \( h \) is the module, \( x_{i-1} \) is the input to the module and \( h(x_{i-1}) \) is the output. This ensures that the original variables are preserved and that new variables are added without interference.
\end{itemize}

\subsection{Categorical Attention Heads}
% add example in figure of rasp

Attention is heart of transformers. In Transformer Programs, we are using categorical attention heads which is inspired by RASP. Categorical Attention makes it easy to interpret how different components of the model are interacting with each other. It learn a binary predicate matrix \( W_{\text{predicate}} \in \{0,1\}^{k \times k} \), which is subject to the condition that the sum of each row in \( W_{\text{predicate}} \) is equals one. The self-attention mechanism is then characterized by a score matrix \( S \in \{0,1\}^{N \times N} \), defined as follows:

\[
S = x W_Q W_{\text{predicate}} (x W_K)^T.
\]
To maintain categorical outputs, hard attention is used in which the output is determined by an $argmax$ operation over the attention scores as follows:
\[
A_i = \text{One-hot} \, \text{argmax}_j S_{i,j},
\]
where \( A_i \) denotes the \( i \)-th row of the attention matrix.

\subsection{Optimization Strategy}

The training of Transformer Programs involves optimizing a distribution over discrete program weights. The following strategies are employed:

\begin{itemize}
    \item \textbf{Discrete Weight Modeling:} Transformer Programs rely on three gating indicators \( \pi_K, \pi_Q, \pi_V \) for selecting key, query, and value variables, along with a predicate matrix \( W_{\text{predicate}} \in \{0, 1\}^{k \times k} \) to determine the attention pattern. To parameterize these discrete weights, the gating indicators \( \pi_K, \pi_Q, \pi_V \) are represented by continuous parameters \( \phi_K, \phi_Q, \phi_V \in \mathbb{R}^m \). Each row of \( W_{\text{predicate}} \) is parameterized by \( \psi_1, \psi_2, \ldots, \psi_k \in \mathbb{R}^k \), which define distributions over the entries. These parameters, collectively denoted as \( \Phi \), define a distribution \( p(\theta \mid \Phi) \) over the discrete weights \( \theta \), modeled as the product of categorical distributions.

    \item \textbf{Hard Attention and Relaxation:} The attention mechanism enforces a hard constraint where each query attends to exactly one key. The attention pattern at position \( i \) is defined as:
    \[
    A_i = \text{One-hot}\big(\arg\max_j S_{i,j}\big),
    \]
    where \( S_{i,j} \) is the attention score between query \( i \) and key \( j \).
    
    During training, the hard attention mechanism is relaxed using the Gumbel-Softmax trick to make it differentiable:
    \[
    A_i = \text{Gumbel-Softmax}(S_i).
    \]
    
    This allows gradients to flow through the model while retaining the ability to enforce hard constraints during inference.
    
    \item \textbf{Loss Function:} Given a classification dataset \( D \) consisting of input-label pairs \( (w, y) \), the objective is to minimize the expected negative log-likelihood:
    \[
    L = \mathbb{E}_{\theta \sim p(\theta \mid \Phi)} \left[ \mathbb{E}_{w, y \sim D} \left[ -\log p(y \mid w; \theta) \right] \right].
    \]
    To compute this efficiently, we approximate the expectation by sampling \( S \) instances of \( \theta \) from \( p(\theta \mid \Phi) \):
    \[
    L \approx \frac{1}{S} \sum_{s=1}^{S} \mathbb{E}_{w, y \sim D} \left[ -\log p(y \mid w; \theta_s) \right].
    \]

    \item \textbf{Gumbel-Softmax Approximation:} Optimizing discrete distributions directly is intractable due to non-differentiability. The Gumbel-Softmax trick addresses this by introducing a differentiable approximation. For a categorical variable \( \pi \), the Gumbel-Softmax sample is defined as:
    \[
    \pi = \text{Softmax}\left(\frac{\phi + g}{\tau}\right),
    \]
    where \( g \sim \text{Gumbel}(0, 1) \) is Gumbel noise, and \( \tau > 0 \) is the softmax temperature. As \( \tau \to 0 \), the Gumbel-Softmax distribution converges to a one-hot representation, enabling the discrete constraints to be met. The softmax temperature \( \tau \) is gradually decreased during training. This annealing process transitions the model from continuous approximations to discrete representations, ensuring that the learned weights align with the hard constraints by the end of training.
    
\end{itemize}

\subsection{Program Extraction}

Once the training process is completed, we convert the trained model into a discrete version by selecting the weights that are most likely, represented as:

\[
\theta^* = \arg\max_{\theta} p(\theta \mid \Phi).
\]

Additionally, hard attention is enforced by applying the argmax operation on the attention values.

The discrete model is then translated into a Python program through a well-defined process, drawing inspiration from RASP (refer to Figure 4). In this approach, each attention head \( h \) is transformed into a predicate function. This function determines whether a specific pair of query and key values satisfies certain conditions, assigning a binary output of either \( 0 \) or \( 1 \).

To implement the attention mechanism, a function named \texttt{select\_closest} is used. This function identifies the nearest key that meets the predicate's criteria for each query. If no matching key is found, it defaults to selecting the first token in the sequence, ensuring the process is consistent and reliable.
