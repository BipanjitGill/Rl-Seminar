\section{Implementation}
\label{ch:implementation}
% How the problem is being addressed. Algorithms, architecture, data, etc. How the implementation is related to the problem formulation above.

To establish a deterministic mapping between Transformer components and RASP-like constructs, the authors apply various constraints to the Transformer model. In the following subsections, we will outline the designs of these programs, the specific constrains applied and the optimization process that ensures effective training.  

\subsection{Distangled Residual Stream}
\label{subsec:distangled-residual-network}

The concept of a disentangled residual stream is key to Transformer Programs, where the token embedding is structured to represent a predefined set of $m$ categorical variables in orthogonal subspaces, ensuring clear separation of information and improving interpretability. Each of these variables has cardinality \( k \), resulting in an input embedding \( x \in \{0,1\}^{N \times mk} \), where \( N \) is the number of words in input. For example, in the \cref{fig:incontext}, the embedding is structured as $m=4$ categorical variables.
    
\begin{figure}[!ht]
    \centering
    \includegraphics[width=1\textwidth]{Results/in-context.png}
    \caption{This figure represent the distangled residual stream of Transformer Programs trained on the in-context learning task\cite{friedman2024learning}. The residual stream encodes four categorical variables, with each module reading a fixed set of variables and writing outputs to distinct subspaces by concatenating.}
    \label{fig:incontext}
\end{figure}

\textbf{Reading Variables:} Each layer reads a fixed set of variables from the residual stream (\cref{fig:incontext}) using a projection matrix \( W \in \mathbb{R}^{mk \times k} \) defined by an indicator \( \pi \in \{0,1\}^m \) where \( \sum_{i=1}^{m} \pi_i = 1 \). The projection matrix is represented as: $W = [\pi_1 I_k, \ldots, \pi_m I_k]^T$, where \( I_k \) is the \( k \times k \) identity matrix. Gating vectors \( \pi_K, \pi_Q, \pi_V \)  control the interaction of each attention head with the residual stream by determining the variables used as key, query, and value.

\textbf{Writing Variables:} Each module writes its output in new non-overlapping subspace in the residual stream by concatenating it with the input (\cref{fig:incontext}). This can be expressed as: \( x_i = [x_{i-1}, h(x_{i-1})] \),  where \( x_{i-1} \) is the input, \( h(x_{i-1})\) is the module's output and \( h \) represents the module. This helps to preserves the original variables while adding new ones without interference.

\subsection{Categorical Attention Heads}
\label{subsec:categorical-attention-heads}

In Transformer Programs, categorical attention heads, inspired by RASP \textcite{weiss2021thinking}, is used to enhance interpretability by defining clear interactions between key-query pairs. These heads learn a binary predicate matrix \( W_{\text{predicate}} \in \{0,1\}^{k \times k} \), where each row sums to one, ensuring that each query interacts with only one key (\cref{fig:incontext-attention}). The attention is represented by a score matrix \( S \in \{0,1\}^{N \times N} \), defined as follows:
\begin{equation}
    S = x  W_Q  W_{\text{predicate}} (x  W_K)^T
    \label{eq:score-matrix}
\end{equation}
To maintain categorical outputs, hard attention is used in which the output is determined by applying $argmax$ operation over the attention scores as follows:
\begin{equation}
    A_i = \text{One-hot} \  (\text {argmax}_j S_{i,j})
    \label{eq:attention-matrix-argmax}
\end{equation}
where \( A_i \) denotes the \( i \)-th row of the attention matrix.

\subsection{Optimization Strategy}

The training of Transformer Programs involves optimizing a distribution over discrete program weights. So, the following strategies are employed:

\begin{itemize}
    \item \textbf{Discrete Weight Modeling:} Transformer Programs use gating indicators \( \pi_K, \pi_Q, \pi_V \) to select key, query, and value variables, and a predicate matrix \( W_{\text{predicate}} \in \{0, 1\}^{k \times k} \) to define the attention patterns (\cref{subsec:distangled-residual-network}). To parameterize these discrete weights, \( \pi_K, \pi_Q, \pi_V \) are represented by continuous parameters \( \phi_K, \phi_Q, \phi_V \in \mathbb{R}^m \), and each row of \( W_{\text{predicate}} \) is parameterized by \( \psi_1, \psi_2, \ldots, \psi_k \in \mathbb{R}^k \), which define distributions over the entries. These parameters, collectively denoted as \( \Phi \), define a distribution \( p(\theta \mid \Phi) \) over the discrete weights \( \theta \), modeled as the product of categorical distributions.
    
    \item \textbf{Loss Function:} For a classification dataset \( D \) with input-output pairs \( (w, y) \), the goal is to minimize the expected negative log-likelihood defined as:
    \begin{equation}
        L = \mathbb{E}_{\theta \sim p(\theta \mid \Phi)} \left[ \mathbb{E}_{w, y \sim D} \left[ -\log p(y \mid w; \theta) \right] \right].
    \end{equation}
    To compute this efficiently, they approximate this by sampling \( S \) instances of \( \theta \) from \( p(\theta \mid \Phi) \):
    \begin{equation}
        L \approx \frac{1}{S} \sum_{s=1}^{S} \mathbb{E}_{w, y \sim D} \left[ -\log p(y \mid w; \theta_s) \right].
    \end{equation}

    \item \textbf{Hard Attention with Gumbel-Softmax Relaxation:} The attention mechanism enforces a hard constraint where each query attends to exactly one key (mentioned in \cref{subsec:categorical-attention-heads}) which is non-differentiable, making it unsuitable for gradient-based optimization. To address this, the Gumbel-Softmax trick by \textcite{jang2016categorical} is applied to relax the hard attention during training, enabling a differentiable approximation of discrete variables. The attention matrix \cref{eq:attention-matrix-argmax} is computed as:
    \[
        A_i = \text{One-hot}\left(\text{Gumbel-Softmax}\left(\log(S_i + \varepsilon)\right)\right)
    \]
    
    for some small $\varepsilon > 0$. For a categorical variable \( \pi \), the Gumbel-Softmax sample is defined as:
    \[
    \pi = \text{Softmax}\left(\frac{\phi + g}{\tau}\right),
    \]
    where \(\phi\) is distribution over  \( \pi \), \( g \sim \text{Gumbel}(0, 1) \) is Gumbel noise, and \( \tau > 0 \) is the softmax temperature which is gradually decreased during training. As \( \tau \to 0 \), the Gumbel-Softmax distribution converges to a one-hot representation, satisfying the discrete constraints.
    
\end{itemize}

\subsection{Program Extraction}

After training, the model is converted to a discrete version by applying the $argmax$ operation to select the most likely weights:
\[
\theta^* = \arg\max_{\theta} p(\theta \mid \Phi).
\]
The discrete model is then translated into a Python program, inspired by RASP \cite{weiss2021thinking} and Tracr \cite{lindner2024tracr}. Each attention head \(h\) is transformed into a predicate function that outputs \(0\) or \(1\), based on whether a query-key pair satisfies specific conditions.
